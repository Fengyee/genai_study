## 问题与结果

仓库原先没有代码或学习内容。本 PR 建立面向熟悉 PyTorch 的研究生的中文 GenAI 自学主线：概率基础、生成模型、DDPM、Flow Matching、图像/视频研究路线与评价协议，并提供不需要数据下载、模型权重或 API key 的 CPU 二维实验与视频时序评价反例。

## 主要内容

- 学习目标、先修依赖、统一符号、推导、反例、练习与参考答案；原始论文和固定版本官方实现来源。
- 原创 DDPM/Flow Matching 实现、独立解析/统计测试、固定随机流和真实样本基线。明确默认短训练欠拟合，不能用8模式覆盖率证明生成质量。
- 3 seeds ×2训练预算×2方法的12次实际运行、原始JSON及图；干净Python3.12环境的hash锁安装和读者首次运行验证。
- 推理checkpoint与固定模型求解器对照；移动光点/帧乱序/静止视频反例，明确不等于视频生成模型。
- 贡献规范、Apache-2.0、质量backlog、恢复检查点；每小时GitHub Actions检查、超时和失败artifact，独立自动编码入口的协作锁。

## 验证与限制

最终检查范围和结果见 records/PROGRESS.md；自动化故障注入与静态验证见 records/automation-validation.md。实验数字是本机实测；不承诺跨机器位级一致或运行时长。

图像/视频部分目前是研究路线，不声称实现大模型训练或预训练推理。arXiv全文访问受环境策略403限制，已核对可访问官方代码并独立推导核心公式；全文逐项核验列入backlog。

每小时workflow仅在合入默认分支后激活，GitHub定时触发可能延迟。自动编码调度与Bark/Codex推送缺少当前可用入口/绑定，没有宣称部署。此PR不部署网站、不自动合并、不调用付费API。
