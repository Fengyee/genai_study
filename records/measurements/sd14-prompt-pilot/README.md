# SD1.4小屋提示探索：事先固定的四请求

动机见[上一轮实测](../../../docs/pretrained-image-report.md)：seed7的三个请求均未观察到明确小屋。本次在查看四张新图之前固定[plan.json](plan.json)，比较原场景提示与短小屋提示，各用seed19和43，其余模型/噪声网格/引导/精度保持。

提示删减同时改变语义内容、长度和场景关系。主要观察为小屋“清楚可见／模糊／未观察到”，定义见plan；过滤或技术失败单列，保存全部请求。单次420秒、总计1800秒上限；根据已有耗时估计总计约18分钟，属于未验证的预算估计。

完成后核对同seed噪声相同、不同seed噪声不同，以及实际参数、20次batch2调用、模型和软件身份；再报告两对具体结果。每条件只有两个新样本，后续结论仍需更多提示、种子与独立读者评价。
