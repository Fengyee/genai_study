## 2. DDPM：从论文公式映射到第 02 章

| 本章主张 | v2 原文定位 | 具体核对与结果 |
| --- | --- | --- |
| 正向一步是 $\mathcal N(\sqrt{1-\beta_t}x_{t-1},\beta_tI)$ | 第 2 页，公式 (2) | 均值中的平方根与噪声方差一致；正文使用 $\alpha_t=1-\beta_t$ 为等价写法 |
| 任意时间的边缘为 $\mathcal N(\sqrt{\bar\alpha_t}x_0,(1-\bar\alpha_t)I)$ | 第 2 页，公式 (4) | 与第 02 章正向边缘和直接采样表达式一致；$\bar\alpha_t$ 是累积乘积，不是单步 $\alpha_t$ |
| 已知 $x_0$ 的后验均值和 $\tilde\beta_t$ | 第 3 页，公式 (6)–(7) | 两个均值系数与方差分母均为 $1-\bar\alpha_t$；本章通过精度配方独立推出相同表达式 |
| 负 ELBO 包括终点 KL、中间 KL 与重建项 | 第 3 页，公式 (5) | 中间项范围为 $t>1$；最后一步 decoder 单独处理，不把 $\tilde\beta_1=0$ 直接塞进中间 KL 的方差分母 |
| 固定反向方差并不只有一种选择 | 第 3 页，§3.2 | 原文讨论 $\sigma_t^2=\beta_t$ 与 $\sigma_t^2=\tilde\beta_t$；本仓库选择后者。对标准正态数据，真实平稳反向方差为 $\beta_t$，与本章 oracle 反例一致 |
| 噪声参数化均值 | 第 4 页，公式 (11) | $\mu_\theta=\alpha_t^{-1/2}[x_t-\beta_t(1-\bar\alpha_t)^{-1/2}\epsilon_\theta]$，与正文及实现一致 |
| 带权噪声 MSE 与简化 MSE 不同 | 第 4 页公式 (12)，第 5 页公式 (14) 和 §3.4 | 时间权重为 $\beta_t^2/[2\sigma_t^2\alpha_t(1-\bar\alpha_t)]$；简化目标使用均匀时间并删除该权重，不能标为完整负 ELBO |
| 训练无需执行所有正向小步，采样按逆序运行 | 第 4 页，Algorithm 1 / 2 | 训练抽取一个离散时间和一份噪声；采样从 $T$ 到 1，最后一步令随机噪声为零。论文索引从 1 开始，代码数组从 0 开始 |
| 图像的最后一步和连续二维实验不同 | 第 4 页，§3.3、公式 (13) | 原文将整数像素缩放到 $[-1,1]$，用高斯分箱积分构造离散 decoder。本仓库未实现该图像似然项；不能把 toy MSE 当作图像 bits/dim |
| 本仓库噪声表是教学配置 | 第 5 页，§4 | 原文图像实验采用 $T=1000$、线性 $\beta_1=10^{-4}$ 到 $\beta_T=0.02$。仓库采用 100 步到 0.1，已明确标注，不是原论文超参复现 |

结论：已核验的 DDPM 核心公式没有发现需要改写的代数错误。本轮补充了原论文图像 decoder 与连续 toy 目标的区别，并替换过时的“当前无法访问 arXiv”说明。章节的 score 条件均值恒等式与标准正态 oracle 是教学推导；本记录不把它们冒充该论文中某个未核对的公式号。

## 3. Flow Matching：正终点方差与零方差教学路径

| 本章主张 | v2 原文定位 | 具体核对与结果 |
| --- | --- | --- |
| 速度场定义连续时间生成流 | 第 2 页，公式 (1)–(4) | ODE 初值时间为 0，源分布被推到后续分布；与本章噪声→数据的方向一致 |
| FM 是对目标边缘速度场的回归 | 第 3 页，公式 (5) | 时间均匀分布在 $[0,1]$；该理论目标涉及一般不可直接计算的边缘速度 |
| 边缘速度是条件速度的后验加权平均 | 第 3 页，公式 (6)–(8)、Theorem 1 | 权重为 $p_t(x\mid x_1)q(x_1)/p_t(x)$，可写为给定当前状态的条件期望；不是简单地对端点无条件平均 |
| CFM 与 FM 仅相差参数无关项 | 第 4 页，公式 (9)、Theorem 2；第 14 页证明 | 原文要求正的边缘密度，证明还声明积分存在、交换积分等条件。本章平方损失条件期望分解一致；不能跳过有限矩/正则性假设 |
| 仿射路径及其导数给出回归目标 | 第 4 页，公式 (10)–(14)；第 5 页 Theorem 3、公式 (15) | 一般条件高斯路径为 $\sigma_tz+\mu_t$，目标是 $\dot\sigma_tz+\dot\mu_t$；不是看到直线就任意选择标签 |
| 原文条件 OT 路径带有 $\sigma_{\min}$ | 第 5–6 页，公式 (20)–(23) | 原文写 $x_t=[1-(1-\sigma_{\min})t]z+ty$，目标 $y-(1-\sigma_{\min})z$。正文现在明确：仓库 $x_t=(1-t)z+ty$、目标 $y-z$ 是 $\sigma_{\min}=0$ 的端点极限 |
| 条件最优不推出边缘全局 OT | 第 6 页，公式 (24) 后的解释 | 原文明确区分条件流的最优传输性质与边缘场是否最优；本章独立端点耦合的限制与之相符 |
| 速度与密度满足连续性方程 | 第 14 页 Theorem 1 证明；第 15 页 Appendix B、公式 (26) | 原文利用对条件密度的积分和 Leibniz 条件；本章用光滑测试函数给出弱形式，需保留交换求导/积分条件 |
| 本仓库不是图像实验配置复现 | 第 19 页 Appendix E；第 20 页 Table 3 | 原文二维示例与图像实验使用不同网络和预算；本仓库的小型 MLP、八高斯分布、固定 Euler 不等价于论文的 ImageNet 实验 |

**本轮纠正的关键缺口**：原第 03 章虽已说明端点奇异性的一般风险，但没有明确区分原文的正 $\sigma_{\min}$ 与代码的零终点噪声。现在已给出一般式、代码特例和端点边界。

- 正 $\sigma_{\min}$ 时，$x_1=y+\sigma_{\min}z$，终点是高斯平滑的数据分布。论文条件映射的可逆性来自 $\sigma_t>0$。
- 取零时，对固定 $y$ 的条件分布在时间 1 退化；条件映射不能再在该端点当作可逆映射。沿训练样本路径直接计算 $y-z$ 有意义，但这不等于在端点代入含 $1/(1-t)$ 的条件速度公式。
- 在离散或奇异数据目标上，不能无条件保证一个光滑、可逆的 ODE 流在有限时间精确得到该目标。仓库从 $[0,1)$ 采样训练时间、用有限步 Euler 近似，不能消除这一理论限制。

本章的两个独立高斯端点例子、条件方差恒等式与 Euler 解析测试属于教学推导；本次未声称在论文中找到逐字相同的例子。

## 4. 从二维教学走向图像：证据可以支持到哪里

这次核对验证了训练目标和采样公式的来源，并补足一个重要的参数边界。它仍不能支持以下越界结论：

| 已有能力/证据 | 尚缺的证据 |
| --- | --- |
| 二维八高斯的噪声预测与速度学习可运行 | 图像的空间归纳偏置、数据预处理、重建/条件语义与真实视觉质量 |
| 同一模型、初始噪声下的 Euler 步数对照 | 原论文自适应求解器、容差与相同质量成本的完整复现 |
| CPU 短训练的损失、覆盖与离群点诊断 | 大规模训练稳定性、图像 FID/似然或方法总体排名 |
| 合成视频的帧序列反例 | 学习到的视频生成、自然运动、遮挡与物理规律 |
| 两篇核心论文的指定公式已核验 | 全课程来源审计，及 2025–2026 年图像/视频进展综述 |

因此，下一项图像实践应先声明合成/真实数据、张量轴和值域、空间模型、资源预算和明确的失败判据，再形成独立运行证据。不能把二维点数组 reshape 成图像，就宣称实现了图像生成研究基线。
