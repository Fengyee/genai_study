# 论文阅读与可复现实验模板

面向已完成 [基础路线](learning-path.md) 的研究生，用于 [04 图像/视频研究方向](chapters/04-image-video-roadmap.md) 的第一份研究计划。先读 [05 评价与实验诊断](chapters/05-evaluation.md)，再复制下列模板到自己的研究笔记。模板中的空项不是已完成成果；计划、测量和未核验主张需要分别填写。

**完成判据**：另一位同学能够判断核心结论的假设、定位原始证据、运行最小基线，并知道什么结果会反驳你的主张。只抄摘要或列更多论文不算完成。

## 7. 评价协议与不确定性

- 主结论：密度 / 保真度 / 覆盖率 / 条件遵循 / 时间一致性 / 成本：
- 主指标定义及方向；次指标和失败案例：
- 特征模型、权重、尺寸变换、数据范围、帧采样/视频裁剪版本：
- 真实参考集、生成样本数、条件抽样方式、分组分析：
- 训练 seed 数、每个条件的采样 seed 数；二者不能混写：
- 独立实验单位；是否存在提示簇、视频帧或同主体相关性：
- 盲评规则、随机展示顺序、允许平局/不确定、评估者数量与限制：
- 区间/误差条的计算方法、重采样单位、涵盖和未涵盖的随机来源：
- 数据泄漏、训练集重叠、近重复与调参泄漏的检查；未知部分：
- 失败、超时、丢弃和重跑规则，完整数量：

只使用固定模型的一组采样，不能声称比较了训练稳定性。只看 FID/FVD，不能声称验证了条件语义或普遍物理正确性。

## 自查练习

**练习**：一份笔记写“模型 A 的 FVD 比论文 B 低 2 分，所以运动更物理；用 5 个采样 seed 得到稳定结果”。至少找出四项缺失。

**参考答案**：没有相同参考视频和预处理协议；没有权重/特征版本与样本量；FVD 不证明物理规律；5 个采样 seed 不等于多个训练运行；没有区间所涵盖的随机来源；没有确认差值是否超出估计变化；没有动作完成度或针对性事件对照。合理下一步是先对齐协议并构造具体运动失败测试，而不是继续增添小数位。
