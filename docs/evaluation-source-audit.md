## 3. 两项独立数学检查

### 高斯距离的两种矩阵写法

Heusel Eq. (6) 写作 $`\mathop{\mathrm{Tr}}\nolimits((AB)^{1/2})`$，其中 $`A,B`$ 是协方差。课程采用对称形式

```math
\mathop{\mathrm{Tr}}\nolimits\bigl((A^{1/2}BA^{1/2})^{1/2}\bigr).
```

当 $`A`$ 正定时，$`AB`$ 与 $`A^{1/2}BA^{1/2}`$ 相似，主平方根具有相同特征值与迹；半正定情形可由添加 $`\varepsilon I`$ 后取极限得到。两种表达的迹一致，课程写法同时显式保留了内部矩阵的对称半正定结构。数值实现还需处理舍入误差、奇异协方差及所用正则化。

缩放全部特征 $`\phi\mapsto a\phi`$ 会使 FID 乘以 $`a^2`$。这与章中“特征坐标平方”的量纲说明一致。

### 均值估计也会产生偏差

固定真实参考均值 $`m_r`$。令生成特征独立同分布、均值 $`\mu_g`$、有限协方差 $`\Sigma_g`$，以 $`N`$ 个样本的均值 $`\bar X`$ 估计，则

```math
\mathbb E\|\bar X-m_r\|_2^2
=\|\mu_g-m_r\|_2^2+\frac{\mathop{\mathrm{Tr}}\nolimits(\Sigma_g)}{N}.
```

由 $`\bar X-\mu_g`$ 的均值为零、协方差为 $`\Sigma_g/N`$ 即可得到。因此，均值差平方本身已经产生依赖生成分布的有限样本偏差；完整 FID 还包含协方差估计与矩阵平方根的影响。

一个可手算的简化例子：参考高斯为 $`\mathcal N(0,1)`$，暂把生成方差视为已知，只从 $`N=10`$ 个样本估计生成均值。

| 生成分布 | 总体高斯距离 | 均值估计增加的期望值 | 简化估计量的期望 |
| --- | ---: | ---: | ---: |
| A：$`\mathcal N(0,4)`$ | $`0+(2-1)^2=1`$ | $`4/10=0.4`$ | 1.4 |
| B：$`\mathcal N(\sqrt{1.1},1)`$ | $`1.1+(1-1)^2=1.1`$ | $`1/10=0.1`$ | 1.2 |

同样的 $`N`$，期望排序仍然反转。这个例子隔离均值项的作用；原论文 Figure 3 提供完整 FID 计算中的经验案例。Chong/Forsyth 的 $`1/N`$ 渐近展开还要求相关矩存在、所展开函数足够光滑；小样本造成奇异协方差时，应另行检查数值与近似条件。

## 4. 将 resize 结论写成可执行的协议

记录三处缩放各自的输入/输出尺寸、库版本、函数、插值核及抗锯齿参数：数据集准备、真实参考图进入特征网络前、生成图进入特征网络前。再记录 RGB/通道顺序、数值范围、裁剪、量化、保存格式、JPEG 参数与特征权重版本。

Parmar 的抗锯齿建议针对下采样：预滤波核宽应适应缩小比例。其 Table 3 中 $`256\to299`$ 的评价缩放属于上采样，而更早的 $`1024\to256`$ 数据准备属于下采样。区分操作位置，才能解释它改变的是训练分布还是评价中的特征分布。

当前库的行为应以固定版本和显式参数核对；论文中的 PyTorch 1.9 / TensorFlow 2.0 结果描述当时测试的调用配置。复用参考统计缓存时，连同生成侧一起核对整条预处理管线；更新管线后重新计算参考统计，并将新协议与历史协议的分数分别报告。
