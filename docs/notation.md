# 术语、符号与约定

本文是全仓库的符号入口。阅读每个算法时先确认**时间方向、变量所在空间、预测目标**；同一篇论文的符号不一定与这里相同。

按概念查阅时使用[中英术语索引](glossary.md)，其中的38组简释链接到具体推导、接口与可执行例子。

| 符号 | 含义与约定 |
| --- | --- |
| $x$ / $x_0$ | 数据样本 / DDPM 中未加噪的数据；向量写法也代表展平的图像或视频 |
| $p_{\mathrm{data}}(x)$ | 未知的数据分布；训练集的经验分布并不等同于它 |
| $p_\theta(x)$ | 参数为 $\theta$ 的生成模型分布；有些模型不能便宜地计算其密度 |
| $c$ | 条件，如文本、类别或参考图像；无条件模型不使用 $c$ |
| $z$ | 潜变量；其含义随章节明确，例如 VAE 潜变量或固定先验采样 |
| $z_{\mathrm{VAE}}$, $z_{\mathrm{diff}}$, $c_{\mathrm{VAE}}$ | VAE重建专题的编解码坐标、扩散坐标和缩放常数；$z_{\mathrm{diff}}=c_{\mathrm{VAE}}z_{\mathrm{VAE}}$，固定SD1.4配置为$c_{\mathrm{VAE}}=0.18215$ |
| $\epsilon$ | 标准高斯噪声，通常 $\mathcal N(0,I)$，与数据独立 |
| $\mathbb E$ | 对下标指定的随机变量取期望；省略下标时须由上下文确定 |
| $D_{\mathrm{KL}}(q\Vert p)$ | $\mathbb E_q[\log q-\log p]$；方向不可互换 |
| $H(p,q)$ | 交叉熵 $-\mathbb E_p[\log q]$；连续情形对应微分交叉熵 |
| $\|a\|_2^2$ | 所有特征维上的平方和；代码中的均值 MSE 还会除以特征数 |
| $\nabla_x\log p_t(x)$ | 对数据变量的 score（分数函数），并非参数梯度或质量评分 |
| $T$, $t$（DDPM） | 总扩散步数和离散索引；$t\in\{1,\ldots,T\}$，$0$ 表示干净数据 |
| $\beta_t$, $\alpha_t$ | DDPM 单步噪声方差与 $1-\beta_t$ |
| $\bar\alpha_t$ | $\prod_{s=1}^t\alpha_s$；$\bar\alpha_0=1$ |
| $t$（flow matching） | 连续归一化时间，$t\in[0,1]$；本仓库 **0 是噪声、1 是数据** |
| $v_\theta(x,t)$ | flow matching 的速度场，单位是“数据坐标 / 归一化时间” |
| $\epsilon_\theta(x_t,t)$ | DDPM 的噪声预测网络；不是直接预测方差 |
| $u$, $w_u$（理论衔接专题） | 数据到噪声时间及该方向的边缘速度；令$t=1-u$时$v_t=-w_{1-t}$ |
| $\alpha(u)$, $\sigma(u)$（高斯路径） | $X_u=\alpha(u)Y+\sigma(u)E$中的数据/噪声幅度；$\alpha(u)$对应离散DDPM的$\sqrt{\bar\alpha_t}$，单步$\alpha_t$沿用上表定义 |
| $Q,K,V$（条件注意力） | 行向量形式的查询、键和值；本专题中查询来自当前特征，键和值来自已编码条件 |
| $L_q,L_c$（条件注意力） | 查询位置数与条件token数；softmax沿$L_c$轴归一化，输出保留$L_q$轴 |
| $f_\theta(x,\sigma)$（一致性专题） | 预测所选概率流轨迹在$\sigma_{\min}>0$处的状态；与局部速度预测分别定义 |
| $\sigma_{\min},\sigma_{\max}$（一致性专题） | VE噪声标准差的最小/最大值；原CM论文分别记作$\epsilon,T$，正文随机噪声另用$Z$ |
| $D$, $N$, $B$ | 单样本维数、训练样本数、批大小；图像和视频的张量轴须另行注明 |

## 时间方向不可混用

DDPM 的正向过程从 $x_0$ 数据走向 $x_T$ 噪声，生成反向执行。flow 实验定义 $x_t=(1-t)\epsilon+t x$，生成从 $t=0$ 走向 $t=1$。因此这两个章节的 $t=0$ **不是同一端点**。引用论文若采用反方向，必须同时变换路径、速度符号和积分区间。

## 数值、单位与评价

- 默认使用自然对数，概率相关量以 nat 计；除以 $\log 2$ 得 bit。图像 bits/dim 还需除以维数，并说明离散化或去量化处理。
- 连续密度可以大于 1；密度依赖坐标单位，点概率仍为 0。比较似然须使用相同数据处理和测度。
- 实验中模型用浮点张量。图片若缩放到 $[-1,1]$，方差、噪声强度及重建误差均在这个坐标系下解释。不要将其直接与 $[0,255]$ 的 MSE 比较。
- 张量维序不是数学定理。PyTorch 常用图像 `B,C,H,W`，视频可能为 `B,C,F,H,W` 或 `B,F,C,H,W`；进入模型前须核对接口，$F$ 是帧数。
- “确定性采样”描述给定初始噪声与求解器后是否再引入随机量，不表示不同初始噪声得到同一样本。
- 所有成本数字必须标为**实际测量**（附硬件、版本、命令）、**理论分析**（附假设）或**未验证估计**。教程的预期现象不自动成为实验结果。

## 常见中英对照

| 中文 | 英文 | 本仓库用法 |
| --- | --- | --- |
| 生成模型 | generative model | 学习数据分布并能够采样的模型族；条件模型学习 $p(x\mid c)$ |
| 潜变量 / 潜空间 | latent variable / latent space | 模型内部表示，不保证每个坐标可解释 |
| 扩散 / 去噪 | diffusion / denoising | 随机扰动过程 / 从带噪输入估计某个目标；去噪并不一定唯一恢复原样本 |
| 分数函数 | score | $\nabla_x\log p(x)$，避免与评估分数混淆 |
| 流匹配 | flow matching | 回归一条概率路径对应的速度场以学习连续生成流 |
| 似然 | likelihood | 将观测固定、视为参数函数的概率或密度 |
| 引导 | guidance | 在采样时改变模型使用的方向或条件组合；不等于重新训练基础模型 |
| 模态丢失 | mode dropping | 模型未覆盖数据分布的部分模式；高观感不保证高覆盖率 |
