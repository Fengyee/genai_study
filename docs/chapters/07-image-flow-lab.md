# 07 · 从二维点到小图像：条件 Flow Matching 实验

**先修与依赖：** [03 Flow matching](03-flow-matching.md) 的直线路径与 Euler 采样、PyTorch 卷积和广播；建议先完成 [05 评价与实验诊断](05-evaluation.md)。

**完成后应能：** 把二维速度回归推广到 `B,C,H,W` 图像张量；解释时间、类别和坐标怎样进入卷积网络；保存并冻结模型比较采样步数；从原始数值、形状与多样性三个角度检查生成结果。

**实践产物与范围：** 在 CPU 上从零训练一个小型条件卷积网络，生成 $`16\times16`$ 的圆盘和轴对齐方形。图像由本仓库程序绘制，无需下载数据、预训练权重或调用付费 API。实验学习受控几何图形的条件分布；迁移到自然图像、文本条件或视频时，还需相应的数据、网络和评价协议。

## 1. 把速度回归推广到图像张量

03 章中每个样本是二维点。本章每个样本有 $`C\times H\times W=1\times16\times16=256`$ 个标量，但保留其空间排列：

| 张量 | 形状 | 含义 |
| --- | --- | --- |
| 干净图像 $`y`$、高斯噪声 $`z`$ | `B,1,16,16` | 一批单通道图像；`B` 索引独立样本 |
| 随机时间 $`t`$ | 每样本一个标量，广播为 `B,1,1,1` | 同一图像所有像素使用同一个路径时间 |
| 带噪图像 $`x_t`$、速度目标 $`y-z`$ | `B,1,16,16` | 维度相同，语义不同 |
| 类别 $`c`$ | `B` | `0` 表示圆盘，`1` 表示轴对齐方形 |
| 网络输出 $`v_\theta(x_t,t,c)`$ | `B,1,16,16` | 每个像素相对于路径时间的强度变化率 |

图像可以展平成 256 维向量使用 03 章公式；卷积网络保留网格结构以利用局部模式和参数共享。实现时同时检查轴的含义和数值形状：`B,H,W,C` 与 `B,C,H,W` 使用不同轴序，逐像素独立采样时间则会改变概率路径。

## 2. 教学数据是怎样画出来的

每次训练重新采样几何参数，再在像素坐标上计算软边图像。类别在 batch 中平衡。

| 对象 | 本章配置 |
| --- | --- |
| 分辨率与通道 | $`16\times16`$、单通道，像素强度位于 $`[0,1]`$ |
| 中心 | 水平和垂直坐标在 $`[5,10]`$ 像素范围内采样 |
| 尺寸 | 圆盘半径或方形半边长在 $`[2,3.5]`$ 像素范围内采样 |
| 边缘 | 以 0.35 像素作为 sigmoid 软化尺度 |
| 类别 | 圆盘 / 轴对齐方形，无旋转、纹理、文字或自然图像背景 |

以像素位置 $`(j,i)`$、中心 $`(c_x,c_y)`$ 为例，圆盘可用内部为正的轮廓函数

```math
h_{\mathrm{disk}}(i,j)=r-\sqrt{(j-c_x)^2+(i-c_y)^2}
```

描述，方形则用

```math
h_{\mathrm{square}}(i,j)=r-\max(|j-c_x|,|i-c_y|).
```

像素取 $`y_{i,j}=\mathop{\mathrm{sigmoid}}\nolimits(h(i,j)/0.35)`$。方形的表达式沿角外方向不是欧氏有符号距离；这里使用它的等值线定义软化方形，不能据此推断边缘在所有方向具有完全相同的欧氏厚度。

软边使亚像素位置和尺寸变化能连续影响像素值，减少硬阈值栅格化的突变。图像由形状、中心和尺寸几个参数决定，集中在低维几何集合上；在线采样增加的是这些参数的组合，任务复杂度仍由几何族限定。

类别条件是形状，中心和尺寸没有作为条件传给网络。因此本章要学的是 $`p(y\mid c)`$：给定“圆盘”后，仍应生成多种位置和大小。

## 3. 带类别条件的直线路径

沿用 03 章的方向：$`t=0`$ 是噪声，$`t=1`$ 是数据。独立采样 $`z\sim\mathcal N(0,I)`$、$`y\sim p_{\mathrm{data}}(y\mid c)`$，并采样 $`t\sim\mathop{\mathrm{Uniform}}\nolimits[0,1]`$：

```math
x_t=(1-t)z+ty,\qquad u_t=y-z.
```

与 03 章不同的是网络额外看到 $`c`$。平方损失的理想回归解为

```math
v^*(x,t,c)=\mathbb E[y-z\mid x_t=x,t,c].
```

本章同样采用零终点噪声；正最小噪声的原论文路径及零噪声端点极限的条件见 [03章](03-flow-matching.md)。程序图形处于低维几何集合，不能保证光滑可逆ODE在有限时间精确匹配它，有限步结果应直接检查。

条件 $`c`$ 可以缩小目标的不确定性，但给定 $`x_t,t,c`$ 后仍可能对应很多噪声和干净图像组合。最优 MSE 一般不为零，其不可约部分来自条件速度的方差。

### 像素、路径状态与速度的取值范围

干净像素位于 $`[0,1]`$，标准高斯噪声却没有有限取值范围；它可以为负，也可以大于 1。中间的 $`x_t`$ 和速度目标 $`y-z`$ 因而都不受 $`[0,1]`$ 限制。

训练时保留 $`z`$ 和 $`x_t`$ 的原始值域；`clamp(0,1)` 会改变声明的概率路径。网络最后一层使用无界输出以表达可正可负的速度，sigmoid 会排除所需的负速度（见练习 C）。图像缩放到 $`[-1,1]`$ 也可以定义一个合理任务，但必须同时修改数据、诊断和实验记录，不能把两套尺度下的 MSE 直接比较。

### MSE 到底除以了什么

实现对 batch、通道和空间位置全部求均值：

```math
\widehat L=\frac{1}{BCHW}\sum_{b=1}^B\sum_{k=1}^C\sum_{i=1}^H\sum_{j=1}^W
\left(v_\theta(x_t,t,c)_{b,k,i,j}-(y-z)_{b,k,i,j}\right)^2.
```

对于固定图像大小，这与“每图求平方和再对 batch 求均值”的目标相差常数 $`CHW=256`$，理想最优解相同，但梯度尺度与优化器行为不必相同。跨实验比较 loss 时需核对目标、数据尺度和归约方式。

像素均值还容易被大面积背景主导：少量边界和前景错误可能在全图平均后变小。因此评估时要结合训练曲线、完整样本、形状诊断和前景统计。

## 4. 卷积网络怎样接收时间与条件

本章使用一个很小的 U-Net 风格卷积网络：空间下采样使信息覆盖更大的区域，恢复分辨率时结合浅层特征。这个结构用于观察空间特征、时间输入与类别条件怎样共同影响速度预测。

输入由带噪图像与展开为空间通道的时间、one-hot 类别、坐标拼接而成：

| 输入部分 | 通道数 | 作用 |
| --- | --- | --- |
| 带噪图像 $`x_t`$ | 1 | 提供当前状态 |
| 时间 $`t`$ | 1 | 告诉网络当前处于路径哪一段 |
| 类别 one-hot | 2 | 区分圆盘和方形 |
| 水平 / 垂直坐标 | 2 | 提供图像中的位置 |

因此第一层看到 6 个通道，输出为 1 个速度通道；扩展通道保持 batch 大小不变。

卷积核共享参数，利于复用局部边缘模式；下采样和多层组合扩大有效感受野。但“使用卷积”不等于模型对任意平移严格等变：有限边界、padding、下采样及显式坐标通道都会影响这一性质。坐标通道还提供绝对位置，帮助模型利用教学数据的中心范围；这种设计假设不应未经检查就搬到另一套数据。

本章的条件接口是两个类别的 one-hot 编码。扩展到 classifier-free guidance 需要训练无条件分支；文本条件还需要文本编码器和相应训练数据。

## 5. 从安装到一组可检查的图像

先完成 [README](../../README.md) 的安装并激活环境。以下命令从仓库根目录执行；参数列表可通过 `python -m genai_study.image_flow --help` 查看。

### 第一步：训练并保存权重

```bash
python -m genai_study.image_flow --steps 1500 --seed 7 --output artifacts/image-flow
```

若只需排查环境和文件输出，先进行低预算 smoke：

```bash
python -m genai_study.image_flow --steps 20 --samples 16 \
  --sampling-steps 8 --seed 7 --output artifacts/image-flow-smoke
```

20 次更新用于检查训练、采样和保存路径；评估图形质量时使用完整训练预算。各次实验使用独立输出目录，以便比较完整结果。若已有 `artifacts/image-flow/checkpoint.pt`，可以直接进入下面的固定模型实验；重训时选择新目录。

### 命令接口

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `--steps` | `1500` | 优化器更新次数，与采样步数不同 |
| `--batch-size` | `64` | 每次更新的图像数量 |
| `--samples` | `128` | 生成与诊断的样本数量 |
| `--sampling-steps` | `40` | 显式 Euler 积分步数，等于本实现的 NFE |
| `--seed` | `7` | 本次训练与生成随机性的基础种子；跨平台位级一致性不保证 |
| `--threads` | `1` | CPU 线程数 |
| `--output` | 必须指定 | 结果目录 |
| `--overwrite` | 默认关闭 | 明确允许覆盖该输出目录中的已有实验文件 |

`--batch-size` 必须为偶数，`--samples` 必须为不少于16的偶数，以保证两个条件都有样本且图像网格完整。

优化器为 Adam，学习率 $`10^{-3}`$，基础卷积宽度为 16。当前接口运行 CPU 单精度、程序生成数据和类别条件。实际版本和每次配置会写入 JSON；成本和多种子观察见[图像实验报告](../image-experiment-report.md)。

### 采样

给定类别 $`c`$，从新的高斯图像噪声出发，执行

```math
x^{(k+1)}=x^{(k)}+\frac1K v_\theta\left(x^{(k)},\frac{k}{K},c\right),\qquad
k=0,\ldots,K-1.
```

每一步更新所有像素，并保留状态的原始值域。由于有限训练、数值误差和模型结构，最终像素可能越过 $`[0,1]`$；程序同时保存原始输出、裁剪诊断和显示图，方便追溯这种变化。

### 第二步：冻结模型，单独改变采样步数

训练完成后，复用其`checkpoint.pt`执行以下命令。若已生成`artifacts/image-solver`，直接读取现有结果完成本节与练习E；重做采样对照时选择新输出目录。

```bash
python -m genai_study.image_solver_study \
  --checkpoint artifacts/image-flow/checkpoint.pt \
  --steps 10 20 40 80 --samples 128 --seed 123 \
  --output artifacts/image-solver
```

`image_flow --steps 1500` 控制训练更新数，`image_solver_study --steps 10 20 40 80` 指定待比较的 Euler 步数。后一命令载入同一组最终权重，每个方案共享以下控制量：

- **初始噪声**：同一批高斯图像，同一索引始终对应同一个起点。
- **类别标签**：同一索引始终使用相同圆盘/方形条件。
- **参考数据**：独立采样的目标图形，用于查看目标分布的几何与多样性统计；另有一批独立目标样本展示有限样本波动。这些图形与噪声独立，评价按分布进行。

步数列表升序去重，每一步调用一次网络，因此 NFE（number of function evaluations）等于步数。保存的 checkpoint 含推理权重与训练元数据；优化器状态未保存，精确恢复训练需要额外状态。使用本仓库在 PyTorch 2.6.0 及以上生成并由自己保管的 checkpoint，载入机制与版本要求见 [实验说明](../../examples/README.md)。早期结果若缺少 checkpoint，请在新目录重新训练。二维 flow 使用 03 章的 `solver_study`，图像使用本节的 `image_solver_study`，二者各自读取对应模型格式。

独立采样生成 `metrics.json`、`arrays.npz` 和 `samples.png`。JSON 记录 checkpoint SHA-256、训练元数据、采样配置、每组成本与分类别诊断。数组包含 `initial`、`labels`、`reference`、`independent_target` 和 `steps_10` 等原始终点；图中各采样方案展示相同索引和标签。耗时是每组单次采样的实际测量，未做预热或重复计时。

### 怎样读原始与裁剪像素的配对差

设升序相邻两个采样步数为 $`K_{j-1}`$ 和 $`K_j`$。JSON 中的 `paired_pixel_rms_difference_from_previous` 为

```math
\Delta_{\mathrm{raw}}(K_j,K_{j-1})=
\sqrt{\frac{1}{BCHW}\sum_{b,k,i,l}
\left(x^{(K_j)}_{b,k,i,l}-x^{(K_{j-1})}_{b,k,i,l}\right)^2}.
```

求和覆盖 batch、通道和空间位置，单位是像素强度；与 03 章每样本向量 L2 差的归约方式不同。`paired_clipped_pixel_rms_difference_from_previous` 将两个终点分别裁剪到 $`[0,1]`$ 后使用同一公式。第一组两项均为 `null`；其余组的 `previous_steps` 明确记录比较对象。

原始差描述两个离散方案对同一起点给出的终点变化；裁剪差描述显示与几何诊断所使用图像的变化。这里没有解析 ODE 真解，80 步仍是有限步近似，因此相邻差只能用于检查步数敏感性。即使配对差减小，学到的速度场仍可能偏离目标分布；同时阅读模板、值域和多样性诊断。

## 6. 训练输出、几何诊断与分布覆盖

| 文件 | 读者应检查什么 |
| --- | --- |
| `metrics.json` | 配置、版本、训练/采样成本与每类诊断；精确字段以当次文件为准 |
| `arrays.npz` | 原始生成图像、参考图像、独立目标样本、标签和训练 loss，供数值复核 |
| `samples.png` | 圆盘与方形的样本是否可辨、是否响应条件，位置与大小是否变化 |
| `loss.png` | 优化过程；结合几何诊断与分布统计分析下降的含义 |
| `checkpoint.pt` | 最终推理权重、架构与训练元数据，供独立采样复用 |

### 先看未裁剪数值

可视化和几何模板诊断使用裁剪到 $`[0,1]`$ 的图像，同时单独报告原始输出的越界比例与平均裁剪幅度。若原始输出为 1.8，展示图中的白色看起来可能正常；仅检查展示图就看不到这个误差。评估值域拟合时应读取原始数组及裁剪诊断。

### 再看是否接近声明的几何族

本实验使用一组已知圆盘和方形模板：中心以 0.5 像素间距、尺寸以 0.25 像素间距枚举。每张输出对各模板求像素平均 MSE，取每类的最小值，再用两个类别的最小值推断最近模板类别。

本章的**粗粒度合格规则**是：与给定条件同类的最近模板 MSE 不超过 `0.01`，且在所有模板中的最近类别也与条件一致。这条规则检查输出是否接近指定几何族，其阈值和模板都依赖本章的合成任务。

模板库是有限网格，数据参数却是连续采样；即使真实目标图像也不一定与某个模板逐像素相等。因此必须同时运行真实数据对照。`0.01` 是本教学实验的显式阈值，不能拿去判断更高分辨率、不同强度尺度或自然图像的质量。

### 最后检查多样性

每个类别固定输出一个标准原型，也可能全部通过上述规则，却没有学到位置和大小的分布。报告因此还检查每类前景质量（像素强度之和）、亮度质心及其变化，并与真实数据对照。这里的“质量”（mass）指像素强度之和；亮度质心按像素强度加权计算位置。

均值和方差相同，中心、尺寸、形状的联合分布仍可能不同。因此模板通过率与这些汇总统计提供的是几何拟合的局部证据，进一步评估还需检查联合分布。

**读者完成标准：** 能完成训练与固定模型采样，定位每类样本和原始数据，解释至少一个指标反例，并用实测结果说明当前模型的拟合情况。

## 7. 练习与参考答案

### A. 同一时间为什么要广播

代码用 `t` 的形状 `B,1,1,1` 与 `B,1,16,16` 图像运算。若改为每个像素独立采样 `t`，是否仍是本章相同的训练问题？

<details><summary>答案</summary>

这会改变训练问题。本章时间表示全图状态沿一条概率路径的位置，网络接收一个标量时间。逐像素独立时间需要重新定义时间条件、训练路径和采样器；当前广播只展开同一个标量值。

</details>

### B. mean 与 sum

batch 为 64，图像为 `1,16,16`，未归约平方误差的所有元素之和为 8192。像素均值 MSE 是多少？若改成每图求和、再对 batch 求均值，结果是多少？

<details><summary>答案</summary>

全均值为 $`8192/(64\times1\times16\times16)=0.5`$；每图求和再平均为 $`8192/64=128`$，相差 256 倍。它们在固定尺寸下的最优解相同，但直接沿用同一学习率不能保证训练轨迹相同。

</details>

### C. 为什么不要给速度加 sigmoid

某像素噪声 $`z=1.5`$，目标强度 $`y=0.2`$。直线路径的目标速度是多少？如果网络输出被限制到 $`[0,1]`$，会发生什么？

<details><summary>答案</summary>

$`y-z=-1.3`$。速度必须允许负值；sigmoid 输出无法表达这个监督目标。网络预测速度与最终图像在 $`[0,1]`$ 内是两个不同要求。

</details>

### D. 模板合格但模式坍塌

生成器对圆盘条件永远输出一个固定圆盘，对方形条件永远输出一个固定方形。模板规则可能全部通过。应该增加哪些检查？

<details><summary>答案</summary>

先按类别检查中心位置、前景质量或估计尺寸的分布及标准差，并与独立真实数据对照；随后检查位置与尺寸的联合分布。固定原型的条件响应可以正确，但类别内变化为零。粗模板通过率只能检查图形接近某些有效模板，不能证明覆盖了目标参数范围。

</details>

### E. 固定模型后，更多采样步数带来了什么

完成第 5 节的训练与独立采样两条命令，从 `artifacts/image-solver/metrics.json` 对照 10、20、40、80 步结果。记录相邻步数的原始/裁剪像素 RMS 差，以及每类的模板通过率和原始越界比例。若原始 RMS 差减小，模板通过率是否也单调上升？裁剪 RMS 比原始 RMS 小说明什么？

下面的命令直接打印待比较字段；若使用了其他输出目录，相应修改路径：

```bash
python - <<'PYCODE'
import json
from pathlib import Path

report = json.loads(Path("artifacts/image-solver/metrics.json").read_text())
for run in report["runs"]:
```
