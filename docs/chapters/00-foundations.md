# 00 · 概率、噪声与实验基础

**先修：** 张量运算、自动微分、线性代数。**依赖：** 无 GenAI 课程依赖。**目标：** 理解“分布”与“样本”的区别，推导噪声线性组合，建立后续扩散/flow 实验的核对方法。约定见[符号表](../notation.md)。

## 1. 从判别到生成

判别任务经常学习 $`p(y\mid x)`$；生成任务学习 $`p(x)`$ 或 $`p(x\mid c)`$ 并从中采样。条件生成与判别都可以建模条件分布，区别主要在于输出空间、目标和采样方式。例如类别预测输出小规模离散变量，文本到图像输出高维连续或离散图像表示。

数据集 $`\{x_i\}_{i=1}^N`$ 给出经验分布

```math
\hat p_N=\frac1N\sum_{i=1}^N\delta_{x_i}.
```

真实数据分布不可直接获得。一个永远输出某张训练图片的“生成器”确实能生成图片，但不覆盖数据的变化；一个随机复读训练集的系统也不能因此证明泛化。后续讨论必须同时关心质量、覆盖率、条件一致性和数据泄漏。

## 2. 密度不是点概率

连续变量满足 $`P(X\in A)=\int_A p(x)\,dx`$，单点概率通常为 0。$`X\sim\mathrm{Uniform}(0,0.1)`$ 时，区间内密度是 10，并不违反概率不超过 1。

坐标变换会改变密度。若 $`Y=aX`$ 且 $`a\ne0`$，则

```math
p_Y(y)=p_X(y/a)/|a|.
```

因此把像素从 $`[0,255]`$ 缩放到 $`[0,1]`$ 后，连续对数密度会产生与维数有关的常数变化。比较不同预处理的负对数似然时，先交代坐标变换和离散化处理，再统一测度与单位。

**数字图像的额外细节。** 8-bit 图像本来是离散数据。对其直接套用连续密度并报告 bits/dim，需要说明去量化或离散概率计算。不能把连续密度值当作某个整型像素配置的概率。

## 3. 条件化、边缘化与采样

生成潜变量模型常写为

```math
p_\theta(x,z)=p(z)p_\theta(x\mid z),\qquad
p_\theta(x)=\int p(z)p_\theta(x\mid z)\,dz.
```

从模型采样可以很容易：先采 $`z`$，再采 $`x\mid z`$。但计算某个 $`x`$ 的边缘密度需要积分，可能很难。因此**容易生成**不意味着**容易计算似然**。

蒙特卡洛估计 $`\mathbb E[f(X)]\approx M^{-1}\sum_m f(X_m)`$ 需要明确采样分布。对于独立同分布、有限方差样本，估计均值的标准误差按 $`M^{-1/2}`$ 缩小；把样本数量加倍不会使误差减半。相关视频帧更不能直接当作同样数量的独立视频样本。

## 4. 高斯噪声：下一章公式的原材料

设 $`X\sim\mathcal N(\mu,\Sigma)`$，$`E\sim\mathcal N(0,I)`$，且二者独立。令 $`Y=aX+bE`$，则

```math
\mathbb E[Y]=a\mu,\qquad
\mathrm{Cov}(Y)=a^2\Sigma+b^2I.
```

线性组合仍为高斯，依据是独立高斯向量的联合高斯性。如果 $`X`$ 不是高斯，上述均值与协方差仍成立，但 $`Y`$ **一般不是高斯**。条件分布却仍是

```math
Y\mid X=x\sim\mathcal N(ax,b^2I).
```

这是理解扩散的重要区别：每个干净样本周围的扰动核是高斯，所有样本混合后的边缘分布通常不是高斯。

取 $`a=\sqrt{\bar\alpha_t}`$，$`b=\sqrt{1-\bar\alpha_t}`$ 即得到 DDPM 常用的带噪样本表达式。它使得无需逐步模拟正向过程即可采样某个时刻的训练输入。$`\bar\alpha_t\to0`$ 时，数据项逐渐消失；有限 $`T`$ 的终点是否足够接近标准高斯，仍取决于噪声日程和数据尺度。

## 5. 随机性与可复现性

“固定种子”设置特定随机数流的起点。跨设备、跨 PyTorch 版本或跨算子实现的逐位一致性需要分别验证。官方 PyTorch [Reproducibility](https://pytorch.org/docs/stable/notes/randomness.html) 说明了可复现性的适用范围；该页面是滚动文档，实验记录应另外固定实际安装版本。

一个可解释的实验记录至少包含：

- 代码提交、依赖版本、CPU/GPU 与数值精度；
- 数据生成或下载方式、训练/评估拆分、归一化；
- 训练种子、采样种子、参数更新次数、batch 大小；
- 采样器、步数与噪声日程；
- 实际耗时及统计口径，结果文件与评价定义。

训练随机性与评估随机性最好分开。先固定评估样本方便定位回归，再用多个评估种子衡量波动。一次运行适合发现故障，不能支持“方法 A 显著优于方法 B”的统计结论。

## 6. 实践与练习

先完成 [README](../../README.md) 的第一次 CPU 运行。阅读输出时回答：输入是几维，噪声来自哪里，训练损失按哪些轴求均值，采样起点是什么分布？这些问题决定了公式是否真的对应代码。

**练习 A：破坏独立性。** 若标量 $`X=E\sim\mathcal N(0,1)`$，$`Y=aX+bE`$，还可以使用 $`a^2+b^2`$ 作为方差吗？

<details><summary>答案</summary>

不可以。此时 $`Y=(a+b)X`$，方差为 $`(a+b)^2`$；一般公式还包含 $`2ab\mathop{\mathrm{Cov}}\nolimits(X,E)`$。例如 $`a=b=1`$ 时方差为 4，而不是 2。

</details>

**练习 B：高斯扰动是否立刻抹掉模式？** 数据 $`X`$ 以相同概率取 $`-3`$ 和 $`3`$，$`Y=X+0.1E`$。写出 $`p_Y`$ 并解释其形状。

<details><summary>答案</summary>

$`p_Y(y)=\tfrac12\mathcal N(y;-3,0.01)+\tfrac12\mathcal N(y;3,0.01)`$。它是两个窄高斯的混合，仍有两个明显模式。条件扰动核为高斯不意味着边缘分布为单高斯。

</details>

**练习 C：缩放损失。** 数据和预测一起从坐标 $`x`$ 变为 $`10x`$，均方误差如何变化？这是否代表模型质量下降？

<details><summary>答案</summary>

MSE 乘以 100。仅改变单位不代表模型质量变化；应在同一坐标系和同一归一化下比较。

</details>

**练习 D：同种子但结果不同。** 改变 batch 大小后保留种子，能否要求训练轨迹逐步一致？

<details><summary>答案</summary>

不能。每步使用的数据与噪声、梯度估计和可能的随机调用顺序都改变了。固定种子是实验控制的一部分，不是跨配置轨迹一致的保证。

</details>
